# 운상 — 구름 위 온라인 교회

구름 위에 떠 있는 탁 트인 대리석 성전을 3D로 걷는 온라인 교회입니다.
빛의 십자가와 성경 인물 동상 사이를 성가대원 캐릭터로 다니며, 함께 접속한 사람과 기도·아멘·촛불을 나눌 수 있습니다.

## 조작
- WASD 또는 방향키: 걷기 (카메라 기준, 대각선 가능)
- 바닥 클릭: 그 자리로 걷기 · 의자 클릭: 앉기
- 드래그: 둘러보기 · 휠 / 두 손가락: 확대·축소

## 파일
- `bitddeul-church.html`: 본문 (claude.ai 아티팩트로도 그대로 올라감)
- `index.html`: 일반 웹용 페이지. `sh build.sh`로 본문에서 만들어짐 (직접 고치지 말 것)
- 함께 보기: claude.ai 안에서는 room 기능, 일반 웹에서는 공용 MQTT 중계 서버(broker.emqx.io)로 위치와 동작을 주고받음
